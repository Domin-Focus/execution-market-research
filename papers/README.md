# Paper Drafting Pipeline

Paper drafts are downstream of research artifacts.

## Stages

1. `outline`: thesis, contribution, falsifiable claims, and section logic.
2. `evidence-map`: every material claim links to a note, experiment, ADR, or primary source.
3. `draft`: prose is written from the evidence map.
4. `internal-review`: challenge novelty, definitions, counterexamples, and overclaiming.
5. `external-review`: collect domain feedback and record responses.
6. `release-candidate`: resolve citations, reproducibility, limitations, and versioning.
7. `published`: tag the exact repository revision and archive supporting artifacts.

## Paper 0 guardrails

Paper 0 should:

- define autonomous execution as an object of study;
- locate the gap across economics, organizations, platforms, AI, and distributed systems;
- state when market coordination is only a hypothesis;
- establish the research agenda.

It should not depend on a specific token, chain, protocol, product, or acquisition strategy.
