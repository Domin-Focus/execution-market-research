# Contributing to EMR

EMR welcomes falsifiable questions, primary sources, reproducible experiments, and precise criticism.

1. Choose one question from `BACKLOG.md` or open one focused issue.
2. Use the research-note template to separate evidence from interpretation.
3. Use the hypothesis/experiment template for testable claims.
4. Record consequential architecture choices as ADRs.
5. Link every paper claim back to a committed source, note, decision, or experiment.

Please do not submit broad promotional claims, token proposals, or implementations without a clearly stated research question.
