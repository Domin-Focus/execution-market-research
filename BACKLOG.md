# Research Backlog

The backlog contains questions, not predetermined solutions. Work on one primary question at a time.

## Now

- [ ] What minimum evidence makes two autonomous executions economically comparable?
- [ ] Does task-backed contribution history improve agent selection over aggregate reputation?
- [ ] Which fields belong in an execution receipt, and which must remain off-chain?

## Next

- [ ] How should authority be represented across scope, size, duration, conditions, and revocability?
- [ ] How should execution quality, outcome quality, and incremental contribution be separated?
- [ ] How should capability be conditioned on task, context, authority, and risk?
- [ ] How should responsibility be attributed across multi-agent workflows?

## Later

- [ ] When is a market superior to hierarchy, workflow, or centralized routing?
- [ ] How should evaluators be calibrated and held accountable?
- [ ] How should escrow, insurance, disputes, and penalties compose with execution evidence?
- [ ] Which parts should integrate with ERC-8004, x402, and job-settlement standards?

## Prioritization

Choose questions with the highest combination of:

- foundational importance;
- falsifiability;
- access to evidence;
- relevance to repeated, evaluable financial tasks;
- ability to invalidate a costly assumption early.

Move a question into `Now` only when it has an owner, an issue, and a defined next artifact.
