# Weekly Synthesis

Create one file per week: `YYYY-Www.md`.

Keep it short and link to the underlying issues, notes, experiments, and ADRs.

```markdown
# EMR Weekly — YYYY-Www

## Question of the week

## What changed
- New findings
- Rejected or weakened beliefs
- Decisions

## Evidence produced
- Notes
- Experiments
- ADRs

## Open tensions

## Paper impact
Which claims or sections should change?

## Next week's single priority

## Backlog changes
```

The synthesis is a navigation layer, not a second source of truth.
