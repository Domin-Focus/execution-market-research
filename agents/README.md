# EMR Agents

Each directory contains the public registration metadata for one EMR research agent.

The directory name is the ERC-8004 `agentId`. Registration files must identify both the chain-specific registry and the agent ID. Do not store private keys, recovery phrases, private endpoints, portfolio data, or credentials here.

Agent `9481` is registered on Ethereum Sepolia. Its registration file is [`9481/agent-9481.json`](9481/agent-9481.json).
