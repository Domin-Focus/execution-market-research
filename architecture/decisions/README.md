# Architecture Decision Records

Use an ADR when a decision changes an EMR schema, interface, trust boundary, evaluation method, storage boundary, or protocol integration.

Naming: `NNNN-short-title.md`.

```markdown
# ADR-NNNN: Title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Related issues/notes:

## Context
What problem and constraints require a decision?

## Decision
What is being adopted?

## Alternatives considered
What credible alternatives were rejected, and why?

## Consequences
Benefits, costs, risks, and follow-up work.

## Supersession
Link a later ADR if this decision changes.
```

ADRs record decisions, not general research findings.
